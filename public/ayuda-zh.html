Wkit 分步指南

你在应用中能做的一切，都在这里慢慢讲清楚：面向传道员和管理员。在 iPhone、iPad 和 Android 上用法相同；如有差别，会标注为 Android 或 iPhone。

适用于每位成员

  1. 首次进入 Wkit
  2. 首页
  3. 提醒：铃铛
  4. 通知：Wkit 会告诉你什么
  5. 你的传道报告（私人）
  6. 区域：查看、交还和申请
  7. 你的账号：换手机、绑定邮箱、语言和删除
  8. 备份

适用于管理员（长老）

  1. 创建会众
  2. 弟兄姊妹名单
  3. 传道小组
  4. 传道聚会
  5. 清洁：轮到谁，以及哪一天、几点
  6. 基督徒生活与传道聚会的节目安排
  7. 公开聚会
  8. 音频和视频/招待员
  9. 其他节目
  10. 通告
  11. 会众日历
  12. 区域：分配、活动和网页面板
  13. 会众订阅
  14. 仅保存在这部手机上的数据

适用于每位成员

1. 首次进入 Wkit

进入 Wkit 不需要邮箱或密码：由你会众的一位长老邀请你，你通过链接或邀请码加入。

  1. 请负责弟兄姊妹名单的长老邀请你。你会连续收到两条消息：先是链接，然后单独一条是邀请码（方便复制）。
  2. 从 App Store（iPhone 和 iPad）或 Google Play（Android）安装 Wkit。
  3. 点按第一条消息中的链接：应用会打开并识别你。
  4. 如果链接没有打开应用，请自己打开应用，点按“我有邀请链接或邀请码”，然后粘贴整条消息或只粘贴邀请码：应用会自动挑出所需内容。
  5. 你会看到几个欢迎界面（“入门指引”），说明哪些内容是共享的、哪些不是。看完后你就进入应用了。
如果邀请码无效（“无效或已过期”），请长老重新生成一个：在你的名片上只需一分钟。
哪些共享，哪些不共享：弟兄姊妹名单、节目安排、清洁、区域和通告由全体会众看到，由长老创建。你的报告只属于你：别人都看不到，连长老也看不到，并且会在你的设备之间同步。

2. 首页

打开 Wkit 后你首先看到的就是它。它让你一目了然地看到属于你的内容；如果没有分配给你的安排，你会看到“近期没有安排”。

  • 接下来的部分：你在基督徒生活与传道聚会和公开聚会中的部分（主席、朗读员、讲者……）。
  • 职责：你在音频和视频/招待员中的职责。
  • 清洁：只有当本周轮到你的小组时才会出现。如果小组监督或助手设定了日期和时间，你会在下方看到（例如“星期日 12:30”）。
  • 其他节目、区域（以及活动，如果有）和报告提醒。
  • 日历：会众的事件（大会、巡回监督的访问……），带有用于设置提醒的铃铛。

底部有五个标签页：首页、节目安排、报告、区域和菜单（弟兄姊妹名单、小组、清洁、通告和设置都在这里）。

3. 提醒：铃铛

每个任务、职责或清洁轮值旁边都有一个铃铛。通过它，手机会在你选定的时间提前提醒你。

  1. 点按任务旁边的铃铛。
  2. 选择提醒的日期和时间。
  3. 确认。铃铛会变成绿色，到时间就会响铃（震动）。
  4. 要取消，再次点按铃铛并选择移除提醒。
如果长老更改了清洁的日期或时间，铃铛会再次建议你按新日期设置提醒。
Android 如果收不到提醒，请在手机设置中检查 Wkit 是否有通知权限，以及它的电池使用是否受到限制。

4. 通知：Wkit 会告诉你什么

有新通告、有安排分配给你，或有与你相关的变动时，Wkit 会通知你。

  1. 第一次手机询问时，请允许通知。
  2. 打开菜单 → 设置 → 通知。
  3. 关闭你不想要的类别（通告、节目安排、音频和视频、清洁、区域……），并选择你希望接收通知的日期和时间。
一台设备一次只接收一个人的通知：即已登录的那个人。如果收不到，请至少在你的账号上打开一次 Wkit，让设备完成注册。

5. 你的传道报告（私人）

报告是个人工具：只有你能看到，连长老也看不到。它保存在你的手机上，并会在你的设备之间同步。

  1. 打开报告标签页。第一次使用时，Wkit 会问你几个问题：你参与哪种服务（传道员、先驱……），以及你每月的时数目标是多少。
  2. 要记录传道活动，点按“新建”，填写日期、小时和分钟以及圣经研究。
  3. 在历史记录中，你可以看到本月和本服务年度的累计，并可编辑或删除记录。
  4. 每月第一天，Wkit 可以在你选定的时间提醒你提交报告。“发送报告”按钮会准备好包含你的时数和研究的消息。
你的报告会同步到你的账号，所以换手机后重新登录就能找回。不过还是建议做一次备份（菜单 → 设置 → 备份）：这是额外的保障。参见第 21 节。

6. 区域：查看、交还和申请

在区域标签页中，你可以看到分配给你的区域，以及你从哪天开始负责。

  1. 区域做完后要交还，请打开它并点按“交还”（或“时间到时提醒”）。负责区域的人会收到通知。
  2. 如果你没有任何区域而想要一个，点按“申请一个区域”。你可以附上一条可选的留言（例如“我想要靠近市中心的区域”）。
  3. 所有区域负责人都会收到通知，第一个有空的人会分配一个给你。分配给你时，你会收到通知。

7. 你的账号：换手机、绑定邮箱、语言和删除

如果你换了手机或手机丢了

  • 如果你没有绑定邮箱（弟兄们不需要），长老会从你在弟兄姊妹名单中的名片给你发送新的邀请。你会找回自己的位置，包括与会众有关的一切以及你的报告。
  • 如果你绑定了邮箱，打开 Wkit，点按“创建账号或以管理员身份登录”，输入邮箱并打开你收到的链接。你会带着原有的一切进入。

在多台设备上使用 Wkit

  • 你可以在 iPhone、iPad 和 Android 上同时使用同一个账号（例如手机和平板）。
  • 要添加另一台设备，长老会从你的名片发送邀请，你在那台设备上打开它。第一台设备上的登录不会被关闭。
  • 你的报告会在你的所有设备之间同步。

绑定邮箱（可选，建议管理员绑定）

  1. 打开菜单 → 设置 → 我的账号 → 绑定我的邮箱。
  2. 输入你的邮箱。你会收到一个确认链接。
  3. 在同一部手机上，用邮件应用打开它。界面会自动关闭，你的账号即绑定完成。

更改语言

Wkit 使用手机的语言。若只想更改 Wkit 的语言：手机设置 → 应用 → Wkit → 语言。

删除账号

菜单 → 设置 → 我的账号 → 删除我的账号。你的账号、你在名单中的名片以及保存在手机上的数据（包括报告）将被删除；你负责的区域将被释放。此操作无法撤销。如果你是唯一的管理员且还有其他弟兄姊妹，必须先指定另一位（在弟兄姊妹名单中打开他的名片并开启“管理员”）。如果你是会众中唯一的人，整个会众也会被删除。

删除账号不会取消会众的订阅（如果由该账号付费）：请在 App Store 取消 iPhone，或在 Google Play → 付款和订阅 → 订阅 中取消 Android。

21. 备份

主要用于为你的报告多留一份副本：虽然报告会在你的设备之间同步，但备份能在你误删时保护你。你可以在菜单 → 设置 → 备份中找到它。

  • 自动备份副本：每月自动备份一次。
  • “立即备份”和“导出备份”：你可以把文件保存到任何地方，或发给自己。
  • “恢复备份”：选择从 Wkit 导出的文件。备份中的数据会添加到你已有的数据中：不会删除任何内容。
iPhone 自动备份保存在你的 iCloud 中。Android 保存在手机上；如果你在 Google 账号中开启了 Android 备份（手机设置 → Google → 备份），在新手机上登录该账号时会自动找回。

适用于管理员（长老）

8. 创建会众

长老只需做一次；然后邀请其他人。

  1. 打开 Wkit，点按“创建账号或以管理员身份登录”。
  2. 输入你的邮箱，点按“发送访问链接”。没有密码：你会收到一个链接，用来确认这个邮箱属于你。
  3. 在同一部手机上打开链接。Wkit 会自动打开。
  4. 填写你的姓名、会众名称、会众编号和国家，然后点按“创建会众”。
  5. 你会看到“长老入门指引”：1）把弟兄姊妹添加到名单中；2）邀请他们。
邮件没收到？检查垃圾邮件文件夹，并点按“我没有收到，请重新发送”。一个邮箱在 Wkit 中只能有一个账号。

9. 弟兄姊妹名单

这是一切的基础：节目安排、小组和任务都使用这份名单中的姓名。你可以在菜单 → 弟兄姊妹名单中找到它。

添加弟兄

  1. 点按 + 按钮（“新弟兄”）。
  2. 输入姓名，并选择是弟兄还是姊妹。
  3. 选择他的角色：已受浸或未受浸的传道员、先驱、助理服务员或长老。
  4. 如有需要，选择他的传道小组，并开启区域负责人、音频和视频/招待员或管理员。
  5. 点按“创建”。
两位同名的弟兄：添加一个能区分他们的标记（例如“小”），以免任务混淆。

邀请弟兄加入 Wkit

  1. 打开该弟兄的名片，点按“邀请”（或“生成链接”）。
  2. 点按“分享邀请”，选择 WhatsApp、短信等。系统会连续发送两条消息：先是链接，然后单独一条是邀请码，方便复制。
  3. 该弟兄打开链接（或粘贴邀请码）即可进入。如果他还没加入，你可以再次分享邀请；如果生成了新的邀请，旧的就会失效。

编辑、删除和指定管理员

  • 点按某位弟兄，选择“编辑”来修改他的信息。
  • 在 Android 上，要删除请点按他那一行的红色图标；在 iPhone 上，把该行向左滑动。他会在所有设备上从名单中移除，他负责的区域会被释放。
  • 管理员可以管理弟兄姊妹、区域、通告和节目安排。你不能删除自己的名片，也不能删除最后一位管理员：请先指定另一位。

10. 传道小组

小组用于传道聚会和清洁。你可以在菜单 → 传道小组 → 列表中找到它们。

  1. 如果还没有，点按“创建传道小组”，选择你想要多少个小组（以后可以用 + 按钮再添加）。
  2. 要把弟兄姊妹分到小组，请进入弟兄姊妹名单，打开每个人的名片，选择他的传道小组。
  3. 回到菜单 → 传道小组 → 列表。在每个小组中，你会看到小组监督、助手，以及按字母顺序排列的成员。
  4. 点按铅笔按钮（编辑）。点按“小组监督”并从该小组的弟兄中选一位；“助手”也同样操作。不能是同一个人。
  5. 点按确认标记完成。
小组监督和助手要在分好弟兄姊妹之后再选，因为只能在该小组的弟兄中选择。如果你把一位弟兄调到另一个小组，他就不再是原小组的监督或助手。
每个小组的监督和助手，即使不是管理员，也可以为自己的小组设定清洁的日期和时间（第 12 节）。

11. 传道聚会

传道聚会是出去传道的集合时间和地点。有通用的（面向全体会众）和每个小组自己的。你可以在菜单 → 传道小组 → 传道聚会中找到它们。需要先创建小组。

  1. 点按“会众”部分（通用聚会）或某个小组的部分。
  2. 在相应的日子点按“添加聚会”，输入标签（例如“上午”或“下午”）、时间，以及（如果需要）地点。
  3. 要编辑聚会，直接修改其字段即可。要删除，点按该行的红色图标。
  4. 弟兄们可以点按地点，在手机地图中打开。
如果某个小组没有自己的聚会，就使用会众的聚会（“没有自己的聚会——使用会众的聚会”）。

12. 清洁：轮到谁，以及哪一天、几点

清洁会在传道小组之间自动轮换：每周轮到不同的小组，从第 1 组开始。你可以在菜单 → 清洁 → 小组中找到。

更改本周负责清洁的小组（管理员）

  1. 点按铅笔按钮（编辑）。
  2. 点按本周轮到的小组。下周会是顺序中的下一个小组。
  3. 点按确认标记。会众的所有设备都会看到这项更改。

设定具体的日期和时间（管理员，以及小组监督和助手）

  1. 在菜单 → 清洁 → 小组中，找到你的小组（或你负责的小组），点按其所在行的铅笔。
  2. 选择日期和时间（例如星期日 12:30），然后点按“保存”。要取消日期，点按“移除日期”。
  3. 该小组的弟兄们会在首页看到：“第 1 组 · 本周”，下方是“星期日 12:30”，并有他们自己的铃铛用来设置提醒。
日期只有在当前这一周（星期一至星期日）时才会显示在首页。你可以提前设定：到了那一周就会显示。过去几周的日期会自动消失。

13. 基督徒生活与传道聚会的节目安排

在节目安排 → 基督徒生活与传道标签页中，你可以创建每周的节目安排并分配各部分。所有弟兄都能看到；只有管理员可以编辑。

  1. 点按“新的一周”，选择聚会日期（该周的任意一天，星期一至星期日）。
  2. Wkit 会按通常的结构创建这一周：神话语的宝藏、用心准备传道工作、基督徒生活。
  3. 点按任意标题可以修改，需要时也可修改时长。用“添加职责”按钮可以添加其他部分。
  4. 在每个部分点按“选择”，指定一位或几位弟兄（例如学生和助手）。若有副班，使用“添加副班会场”。
  5. 同时选择诗歌和祷告，然后点按“保存节目安排”。
  • 要查看其他周，使用周切换器（“上一周” / “下一周”）；也可以在那里编辑或删除它。
  • 弟兄们被分配到某个部分时会收到通知，并在首页看到。
  • 每周的节目安排会在星期日结束时自动消失。

14. 公开聚会

在节目安排 → 公开聚会中准备每次周末聚会。

  1. 点按“新的公开演讲”并选择日期。如果该日期已有聚会，Wkit 会提醒你。
  2. 选择主席、讲者，并输入演讲标题。
  3. 选择守望台研读班朗读员，以及诗歌和祷告。
  4. 保存。弟兄们会在首页看到自己的部分。

15. 音频和视频/招待员

在菜单 → 音频和视频/招待员中，你可以分配每周的职责：音频、视频、麦克风、招待员、Zoom、计时……

  1. 点按“新的一周”并选择聚会日期。
  2. 在每项职责点按“选择”并指定一位弟兄。有些职责（如麦克风）允许多位弟兄（“添加弟兄”）。
  3. 如果列表中没有某项职责，点按“添加职责”并为它命名。
  4. 保存。每位弟兄都会在他首页的职责部分看到，并带有他自己的铃铛。

16. 其他节目

用于会众安排的其他一切、不属于聚会的事项：例如接送无法前来的弟兄，或帮助传道员。每个节目有自己的频率。你可以在菜单 → 其他节目中找到。

  1. 点按“新节目安排”。输入名称并选择多久进行一次：每天、每周、每月或每年。
  2. 点按“创建第一周”（或“新时段”）并选择日期：该周、该月或该年的任意一天。
  3. 点按“添加职责”：输入可选的标签（例如“提早接送”）并选择一位弟兄或姊妹。
  4. 保存。每个人都会在首页的“其他节目”部分看到，时段结束后会自动消失。

17. 通告

通告由管理员创建；只面向自己小组的通告，则由每个传道小组的监督和助手创建。通告对象范围内的弟兄们能看到。你可以在菜单 → 通告中找到。

  1. 点按“新通告”并输入留言。
  2. 默认在你保存后会立即发布，所有人都会收到通知。
  3. 如果你希望晚些发出，开启“预定稍后发送”并选择日期和时间：在此之前没人能看到，到点时所有人都会收到通知。
  4. 保存。要删除通告，点按它并选择“删除”：对所有人都会消失。

只发给一个小组的通告

  • 每个传道小组的监督和助手，即使不是管理员，也会看到 + 按钮，他们的通告只会发给本小组的成员。
  • 同时也有小组的管理员，在创建通告时可以开启“只把这条通告发给我所在小组的成员”。

22. 会众日历

让所有人都能看到会众的事件，例如巡回大会或巡回监督的访问。只有管理员可以创建。

  1. 打开菜单 → 日历，点按“添加事件”。
  2. 输入标题并点按事件的日期：如果持续几天，就逐一点按。
  3. 保存。所有人都会在首页的“日历”部分看到，并有一个用于设置提醒的铃铛。
  4. 要修改或删除，打开该事件并选择“编辑事件”或“删除事件”。

18. 区域：分配、活动和网页面板

拥有区域负责人权限的人，在区域标签页中管理全体会众的区域（传道员只能看到自己的）。

分配和接收区域

  • 点按一个区域，选择“分配”（或“分配给一位传道员”）和一位弟兄。你会看到谁负责以及从什么时候开始，还有哪些已过期或从未分配。
  • 当传道员申请区域时，所有区域负责人都会收到通知（“区域申请”）；第一个有空的人分配给他。
  • 当弟兄交还区域时，该区域变为空闲，并记录日期。

活动

  • “新活动”会在一段时间内把所有区域重新从零开始记录。系统会创建当前区域的一份副本用于单独分发；日常区域不受影响。
  • 同一时间只能有一个进行中的活动。要结束它，选择“删除活动”：它的分配会被删除，一切恢复正常。

S-13 卡片和网页面板

  • 在工具中，你可以生成 PDF 格式的 S-13 卡片（每个分区一张）用于分享。
  • 区域网页面板在电脑浏览器中打开。要给区域负责人访问权限：在弟兄姊妹名单中打开他的名片，点按“面板访问权限” → “生成链接”。链接是个人专属的；他用你选定的、你可随时更改的6位数字密码登录。
面板链接就像密码：不要分享给不该有访问权限的人。如果你生成了新的链接，旧的就会失效。

19. 会众订阅

要让所有弟兄姊妹都能完整使用，需要会众年度订阅。由一位管理员付费，涵盖所有弟兄姊妹，iPhone 和 Android 均适用。其他弟兄姊妹无需付费。

  1. 打开菜单 → 设置 → 会众订阅。
  2. 点按“为会众订阅”。确认前你会看到年费；如果有免费试用期，试用结束前不会扣费。
  3. 在 App Store（iPhone）或 Google Play（Android）中确认。完成：全体会众都可使用。
  • 每年自动续订，除非你在期限结束前至少 24 小时取消。
  • 要管理或取消：iPhone iPhone 设置 → 你的姓名 → 订阅；Android Google Play → 你的头像 → 付款和订阅 → 订阅（或 Wkit 的“在 Google Play 中管理或取消”按钮）。
  • 如果你换了手机，请在同一界面点按“恢复购买”。
  • 如果订阅到期，会众会进入只读模式：所有内容仍可查看，不会删除任何内容。续订后即可再次编辑。
Wkit 从不查看或存储你的付款数据：由 Apple 或 Google 处理。

20. 仅保存在这部手机上的数据

如果你离线使用过 Wkit，或在你的会众创建之前使用过，应用可能会询问如何处理仅保存在这部手机上的数据（例如弟兄姊妹或通告）。你有两个选择：“上传”到会众（所有人都会看到），或“放弃”。在你决定之前不会发生任何事。
