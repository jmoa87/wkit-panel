すべてのメンバー向け

1. Wkit に初めて入る

Wkit に入るのにメールアドレスもパスワードも必要ありません。会衆の長老があなたを招待し、あなたはリンクまたはコードで参加します。

  1. 兄弟姉妹リストを管理している長老に、招待してもらってください。続けて2通のメッセージが届きます。最初にリンク、次に別メッセージでコード（コピーしやすいように）です。
  2. App Store（iPhone と iPad）または Google Play（Android）から Wkit をインストールします。
  3. 最初のメッセージのリンクをタップします。アプリが開き、あなたを認識します。
  4. リンクでアプリが開かない場合は、ご自身でアプリを開き、「招待リンクまたはコードがあります」をタップして、メッセージ全体またはコードだけを貼り付けてください。アプリが必要な部分を選びます。
  5. 何が共有され、何が共有されないかを説明する歓迎画面（「最初のステップ」）がいくつか表示されます。終わると、中に入れます。
コードが使えない場合（「無効、または期限切れ」）は、長老に新しいコードを作ってもらってください。あなたのカードから1分でできます。
共有されるものとされないもの：兄弟姉妹リスト、プログラム、清掃、区域、お知らせは会衆全体が見られ、長老が作成します。報告はあなただけのものです。ほかの誰にも、長老にも見えず、あなたのデバイス間で同期されます。

2. ホーム画面

Wkit を開いて最初に目にする画面です。自分に関することがひと目で分かります。割り当てがない場合は「近い割り当てはありません」と表示されます。

  • 次の部分：「クリスチャンとしての生活と奉仕」の集まりや公開講演でのあなたの部分（司会者、朗読者、講演者など）。
  • 責任：音声・映像/案内係でのあなたの担当。
  • 清掃：今週があなたのグループの番のときだけ表示されます。グループの監督や助け手が日付と時刻を決めている場合は、その下に表示されます（例：「日曜日 12:30」）。
  • その他のプログラム、区域（キャンペーンがあればそれも）、そして報告のリマインダー。
  • カレンダー：会衆の予定（大会、巡回監督の訪問など）。リマインダー用のベル付きです。

下には5つのタブがあります：ホーム、プログラム、報告、区域、メニュー（兄弟姉妹リスト、グループ、清掃、お知らせ、設定はここにあります）。

3. リマインダー：ベル

各タスク、責任、清掃の当番の横にベルがあります。これを使うと、あなたが選んだ時刻に、前もってスマートフォンが知らせてくれます。

  1. タスクの横のベルをタップします。
  2. リマインダーの日付と時刻を選びます。
  3. 確定します。ベルが緑色になり、時間になると鳴ります（振動します）。
  4. 削除するには、もう一度ベルをタップして、リマインダーの削除を選びます。
長老が清掃の日付や時刻を変更した場合、ベルが新しい日付でリマインダーを設定し直すよう提案します。
Android リマインダーが届かない場合は、スマートフォンの設定で Wkit に通知の許可があるか、バッテリー使用が制限されていないかを確認してください。

4. 通知：Wkit がお知らせする内容

新しいお知らせがあったとき、何かが割り当てられたとき、あなたに関わる変更があったときに、Wkit が通知します。

  1. 初回にスマートフォンから聞かれたら、通知を許可してください。
  2. メニュー → 設定 → 通知を開きます。
  3. 不要なカテゴリ（お知らせ、プログラム、音声・映像、清掃、区域など）をオフにし、通知を受け取りたい曜日と時刻を選びます。
デバイスが通知を受け取れるのは、一度にひとり分だけです。セッションを開いている人の通知です。届かない場合は、デバイスが登録されるよう、少なくとも一度は自分のアカウントで Wkit を開いてください。

5. あなたの奉仕報告（非公開）

報告は個人用のツールです。見られるのはあなただけで、長老にも見えません。スマートフォンに保存され、あなたのデバイス間で同期されます。

  1. 報告タブを開きます。初回は、Wkit がいくつか質問します：どのような奉仕をしているか（伝道者、開拓者など）と、月ごとの時間の目標です。
  2. 奉仕を記録するには、「新規」をタップして、日付、時間と分、聖書研究を入力します。
  3. 履歴では、月ごとと奉仕年度の合計を確認でき、記録の編集や削除もできます。
  4. 毎月1日に、Wkit は選んだ時刻に報告を送るようリマインドできます。「報告を送る」ボタンで、時間と研究を入れたメッセージが用意されます。
報告は同期されます。アカウントに紐づいているので、機種変更してもログインし直せば元に戻ります。それでもバックアップ（メニュー → 設定 → バックアップ）を作っておくと安心です。21 の項目をご覧ください。

6. 区域：確認、返却、依頼

区域タブでは、割り当てられた区域と、いつから担当しているかが分かります。

  1. 区域を回り終えて返却するには、区域を開いて「返却」（または「時間切れを通知する」）をタップします。区域の担当者に通知が届きます。
  2. 区域がなく、区域がほしい場合は、「区域を依頼」をタップします。任意でメッセージを添えられます（例：「中心部の近くの区域をお願いしたいです」）。
  3. 区域の責任者全員に通知が届き、最初に対応できる人が区域を割り当てます。割り当てられると、通知が届きます。

7. あなたのアカウント：機種変更、メールの紐づけ、言語、削除

スマートフォンを替えた場合や紛失した場合

  • メールアドレスを紐づけていない場合（兄弟たちは不要です）、長老が兄弟姉妹リストのあなたのカードから新しい招待を送ります。会衆に関するすべてと報告が、元の場所に戻ります。
  • メールアドレスを紐づけている場合は、Wkit を開き、「アカウントを作成、または管理者としてログイン」をタップして、メールアドレスを入力し、届いたリンクを開きます。以前のままの状態で入れます。

複数のデバイスで Wkit を使う

  • iPhone、iPad、Android で同じアカウントを同時に使えます（たとえばスマートフォンとタブレット）。
  • 別のデバイスを追加するには、長老があなたのカードから招待を送り、あなたはそのデバイスでそれを開きます。最初のデバイスのログインは終了しません。
  • 報告はすべてのデバイス間で同期されます。

メールの紐づけ（任意。管理者にお勧め）

  1. メニュー → 設定 → マイアカウント → メールアドレスを紐づけるを開きます。
  2. メールアドレスを入力します。確認用のリンクが届きます。
  3. 同じスマートフォンで、メールアプリからそれを開きます。画面は自動的に閉じ、アカウントが紐づけられます。

言語の変更

Wkit はスマートフォンの言語を使います。Wkit だけ変えるには：スマートフォンの設定 → アプリ → Wkit → 言語。

アカウントの削除

メニュー → 設定 → マイアカウント → アカウントを削除。あなたのアカウント、リストのカード、スマートフォンに保存されたデータ（報告を含む）が削除され、担当していた区域は解放されます。元に戻せません。あなたが唯一の管理者で、ほかに兄弟姉妹がいる場合は、先に別の人を指名する必要があります（兄弟姉妹リストでその人のカードを開き、「管理者」をオンにします）。会衆にいるのがあなただけの場合は、会衆全体も削除されます。

アカウントを削除しても、このアカウントが支払っている場合の会衆のサブスクリプションは解約されません。解約は App Store iPhone または Google Play → お支払いと定期購入 → 定期購入 Android で行います。

21. バックアップ

主に、報告の予備のコピーを持つためのものです。報告はデバイス間で同期されますが、誤って削除した場合にバックアップが守ってくれます。メニュー → 設定 → バックアップにあります。

  • 自動コピー：月に一度、自動でコピーを作成します。
  • 「今すぐコピーを作成」と「バックアップを書き出す」：ファイルを好きな場所に保存したり、自分に送ったりできます。
  • 「バックアップを復元」：Wkit から書き出したファイルを選びます。バックアップのデータは、すでにあるデータに追加されます。何も削除されません。
iPhone 自動コピーはあなたの iCloud に保存されます。Android スマートフォンに保存され、Google アカウントで Android のバックアップを有効にしている場合（スマートフォンの設定 → Google → バックアップ）は、新しいスマートフォンでそのアカウントにログインすると自動で復元されます。

管理者（長老）向け

8. 会衆を作成する

長老が一度だけ行います。その後、ほかの人を招待します。

  1. Wkit を開き、「アカウントを作成、または管理者としてログイン」をタップします。
  2. メールアドレスを入力して、「アクセスリンクを送信」をタップします。パスワードはありません。メールアドレスがあなたのものであることを確認するリンクが届きます。
  3. 同じスマートフォンでリンクを開きます。Wkit が自動で開きます。
  4. お名前、会衆名、会衆番号、国を入力して、「会衆を作成」をタップします。
  5. 「長老としての最初のステップ」が表示されます：1）兄弟姉妹リストにメンバーを追加する、2）招待する。
メールが届きませんか？迷惑メールフォルダを確認し、「届いていません。もう一度送信」をタップしてください。ひとつのメールアドレスで作れる Wkit のアカウントは1つだけです。

9. 兄弟姉妹リスト

すべての土台です。プログラム、グループ、タスクは、このリストの名前を使います。メニュー → 兄弟姉妹リストにあります。

兄弟姉妹を追加する

  1. + ボタン（「新しい兄弟姉妹」）をタップします。
  2. 名前を入力し、兄弟か姉妹かを選びます。
  3. 役割を選びます：バプテスマを受けた/受けていない伝道者、開拓者、奉仕の僕、長老。
  4. 必要に応じて、野外奉仕のグループを選び、区域の責任者、音声・映像/案内係、管理者をオンにします。
  5. 「作成」をタップします。
同じ名前の兄弟が2人いる場合：区別できるもの（たとえば「Jr.」）を付け足して、タスクが混ざらないようにしてください。

兄弟姉妹を Wkit に招待する

  1. その人のカードを開き、「招待」（または「リンクを作成」）をタップします。
  2. 「招待を共有」をタップして、WhatsApp やメッセージなどを選びます。続けて2通のメッセージが送られます。最初にリンク、次に別メッセージでコードです。コピーしやすくするためです。
  3. その人がリンクを開く（またはコードを貼り付ける）と入れます。まだ参加していなければ、招待をもう一度共有できます。新しく作成すると、前の招待は使えなくなります。

編集、削除、管理者の指名

  • 兄弟姉妹をタップして、「編集」を選ぶと、情報を変更できます。
  • Android で削除するには、その行の赤いアイコンをタップします。iPhone では行を左にスワイプします。すべてのデバイスでリストから削除され、担当していた区域は解放されます。
  • 管理者は、兄弟姉妹、区域、お知らせ、プログラムを管理できます。自分のカードと最後の管理者は削除できません。先に別の人を指名してください。

10. 野外奉仕のグループ

グループは、野外奉仕の集まりと清掃に使います。メニュー → 野外奉仕のグループ → リストにあります。

  1. まだない場合は、「野外奉仕のグループを作成」をタップして、いくつのグループにするかを選びます（あとから + ボタンで追加できます）。
  2. 兄弟姉妹をグループに割り当てるには、兄弟姉妹リストで各人のカードを開き、その人の野外奉仕のグループを選びます。
  3. メニュー → 野外奉仕のグループ → リストに戻ります。各グループに、グループの監督、助け手、そしてアルファベット順のメンバーが表示されます。
  4. 鉛筆ボタン（編集）をタップします。「グループの監督」をタップして、そのグループの兄弟から選びます。「助け手」も同様にします。同じ人にはできません。
  5. 確認マークをタップして終了します。
グループの監督と助け手は、兄弟姉妹を割り当てた後に選びます。そのグループの兄弟からしか選べないからです。兄弟を別のグループに移すと、前のグループの監督や助け手ではなくなります。
各グループの監督と助け手は、管理者でなくても、自分のグループの清掃の日付と時刻を決めることができます（12 の項目）。

11. 野外奉仕の集まり

野外奉仕の集まりは、奉仕に出かけるための集合時刻と場所です。全体用（会衆全体）と各グループ独自のものがあります。メニュー → 野外奉仕のグループ → 野外奉仕の集まりにあります。先にグループを作成しておく必要があります。

  1. 「会衆」の項目（全体の集まり）、またはグループの項目をタップします。
  2. 該当する曜日で「集まりを追加」をタップし、ラベル（例：「朝」「午後」）、時刻、必要なら場所を入力します。
  3. 集まりを編集するには、項目を直接変更します。削除するには、その行の赤いアイコンをタップします。
  4. 兄弟たちは場所をタップして、スマートフォンの地図で開けます。
グループに独自の集まりがない場合は、会衆の集まりが使われます（「独自の集まりはありません。会衆の集まりを使用します」）。

12. 清掃：誰の番か、何曜日の何時か

清掃は、野外奉仕のグループの間で自動的に回ります。毎週ちがうグループの番になり、グループ1から始まります。メニュー → 清掃 → グループにあります。

今週清掃するグループを変更する（管理者）

  1. 鉛筆ボタン（編集）をタップします。
  2. 今週の番のグループをタップします。来週は順番で次のグループになります。
  3. 確認マークをタップします。会衆のすべてのデバイスに変更が表示されます。

正確な日付と時刻を決める（管理者、およびグループの監督と助け手）

  1. メニュー → 清掃 → グループで、自分のグループ（または担当するグループ）を見つけて、その行の鉛筆をタップします。
  2. 日付と時刻（例：日曜日の12:30）を選び、「保存」をタップします。日付を消すには、「日付を削除」をタップします。
  3. そのグループの兄弟たちには、ホーム画面に「グループ1 · 今週」、その下に「日曜日 12:30」と表示され、リマインダーを設定するためのベルもあります。
日付がホーム画面に表示されるのは、今週（月曜日から日曜日）の場合だけです。前もって設定しておくこともでき、その週が来たら表示されます。過ぎた週の日付は自動で消えます。

13. 「クリスチャンとしての生活と奉仕」の集まりのプログラム

プログラム → クリスチャンとしての生活と奉仕タブで、毎週のプログラムを作成し、部分を割り当てます。兄弟全員が見られ、編集できるのは管理者だけです。

  1. 「新しい週」をタップして、集まりの日付（その週のどの日でも、月曜日から日曜日）を選びます。
  2. Wkit は、通常の構成で週を作成します：神の言葉の宝、野外奉仕に励む、クリスチャンとしての生活。
  3. タイトルをタップして変更でき、必要なら所要時間も変更できます。「責任を追加」ボタンでほかの部分を追加できます。
  4. 各部分で「選択」をタップして、兄弟（たとえば生徒と助け手）を指定します。補助会場には「補助会場を追加」を使います。
  5. 歌と祈りも選んで、「プログラムを保存」をタップします。
  • 別の週を見るには、週の切り替え（「前の週」 / 「次の週」）を使います。そこから編集や削除もできます。
  • 部分が割り当てられると、兄弟たちに通知が届き、ホーム画面にも表示されます。
  • その週のプログラムは、日曜日が終わると自動で消えます。

14. 公開講演の集まり

プログラム → 公開講演で、週末の各集まりを準備します。

  1. 「新しい公開講演」をタップして、日付を選びます。その日付にすでに集まりがある場合は、Wkit が警告します。
  2. 司会者と講演者を選び、講演のタイトルを入力します。
  3. ものみの塔研究の朗読者、そして歌と祈りを選びます。
  4. 保存します。兄弟たちは、ホーム画面で自分の部分を確認できます。

15. 音声・映像/案内係

メニュー → 音声・映像/案内係で、毎週の責任（音声、映像、マイク、案内係、Zoom、時間管理など）を割り当てます。

  1. 「新しい週」をタップして、集まりの日付を選びます。
  2. 各責任で「選択」をタップして、兄弟を指定します。マイクのように複数の兄弟を指定できるものもあります（「兄弟姉妹を追加」）。
  3. リストにない別の責任には、「責任を追加」をタップして名前を付けます。
  4. 保存します。各兄弟のホーム画面の責任の項目に、本人のベルとともに表示されます。

16. その他のプログラム

会衆が組織する、集まり以外のそのほかすべてのために使います。たとえば、来られない兄弟姉妹の送迎や、伝道者への支援など。それぞれのプログラムには独自の頻度があります。メニュー → その他のプログラムにあります。

  1. 「新しいプログラム」をタップします。名前を入力し、実施の頻度（毎日、毎週、毎月、毎年）を選びます。
  2. 「最初の週を作成」（または「新しい期間」）をタップして、日付（その週、月、年のどの日でも）を選びます。
  3. 「責任を追加」をタップします：任意のラベル（例：「早めに送迎」）を入力し、兄弟または姉妹を選びます。
  4. 保存します。各人のホーム画面の「その他のプログラム」の項目に表示され、期間が終わると自動で消えます。

17. お知らせ

お知らせは管理者が作成します。また、自分のグループ向けに限り、各野外奉仕のグループの監督と助け手も作成できます。宛先の兄弟姉妹が見られます。メニュー → お知らせにあります。

  1. 「新しいお知らせ」をタップして、メッセージを入力します。
  2. デフォルトでは、保存するとすぐに即時公開され、全員に通知が届きます。
  3. あとで公開したい場合は、「後で送るよう予約」をオンにして、日付と時刻を選びます。その時までは誰にも見えず、その時刻に全員へ通知が届きます。
  4. 保存します。お知らせを削除するには、それをタップして「削除」を選びます。全員から消えます。

ひとつのグループだけへのお知らせ

  • 各野外奉仕のグループの監督と助け手には、管理者でなくても + ボタンが表示され、そのお知らせは自分のグループのメンバーだけに届きます。
  • 自分のグループも持っている管理者は、お知らせを作成するときに「このお知らせを自分のグループのメンバーだけに送る」をオンにできます。

22. 会衆のカレンダー

巡回大会や巡回監督の訪問など、会衆の予定を全員が見られるようにします。作成できるのは管理者だけです。

  1. メニュー → カレンダーを開いて、「予定を追加」をタップします。
  2. タイトルを入力して、予定の日をタップします。複数日にわたる場合は、それぞれの日をタップします。
  3. 保存します。全員がホーム画面の「カレンダー」の項目で確認でき、リマインダーを設定するためのベルもあります。
  4. 変更や削除をするには、予定を開いて「予定を編集」または「予定を削除」を選びます。

18. 区域：割り当て、キャンペーン、ウェブパネル

区域の責任者の権限を持つ人は、区域タブで会衆全体の区域を管理します（伝道者は自分の区域だけが見られます）。

区域の割り当てと受け取り

  • 区域をタップして、「割り当てる」（または「伝道者に割り当てる」）と兄弟を選びます。誰がいつから担当しているか、また期限切れや割り当て歴なしの区域も確認できます。
  • 伝道者が区域を依頼すると、区域の責任者全員に通知が届きます（「区域の依頼」）。最初に対応できる人が割り当てます。
  • 兄弟が区域を返却すると、その区域は空きになり、日付が記録されます。

キャンペーン

  • 「新しいキャンペーン」は、一定の期間、すべての区域を最初から記録し直します。現在の区域のコピーが作られ、別に配布できます。通常の区域には影響しません。
  • 進行中のキャンペーンは同時にひとつだけです。終了するには「キャンペーンを削除」を選びます。割り当ては削除され、すべてが通常に戻ります。

S-13 カードとウェブパネル

  • ツールでは、共有用にPDF の S-13 カード（区域の区分ごとに1枚）を作成できます。
  • 区域のウェブパネルは、パソコンのブラウザで開きます。区域の責任者にアクセスを与えるには：兄弟姉妹リストでその人のカードを開き、「パネルへのアクセス」 → 「リンクを作成」をタップします。リンクは個人用です。本人は、あなたが決めて、いつでも変更できる6桁のパスワードでログインします。
パネルのリンクはパスワードのようなものです。アクセスすべきでない人には共有しないでください。新しく作成すると、前のリンクは使えなくなります。

19. 会衆のサブスクリプション

兄弟姉妹全員がすべての機能を使えるようにするには、会衆の年間サブスクリプションが必要です。管理者がお支払いすれば、すべての兄弟姉妹が対象になります。iPhone でも Android でも同じです。ほかの兄弟姉妹の負担はありません。

  1. メニュー → 設定 → 会衆のサブスクリプションを開きます。
  2. 「会衆を登録」をタップします。確定する前に年額が表示されます。無料体験期間がある場合は、それが終わるまで請求されません。
  3. App Store（iPhone）または Google Play（Android）で確定します。完了です。会衆全体が使えるようになります。
  • 期間終了の24時間前までに解約しない限り、毎年自動で更新されます。
  • 管理または解約するには：iPhone iPhone の設定 → お名前 → サブスクリプション。Android Google Play → プロフィール → お支払いと定期購入 → 定期購入（または Wkit の「Google Play で管理または解約」ボタン）。
  • スマートフォンを替えた場合は、同じ画面で「購入を復元」をタップします。
  • サブスクリプションが期限切れになると、会衆は閲覧のみのモードになります。すべて引き続き見られ、何も削除されません。更新すると、また編集できます。
Wkit があなたの支払いデータを見たり保管したりすることはありません。Apple または Google が処理します。

Wkit をオフラインで使っていた場合や、会衆が作成される前に使っていた場合、アプリがこのスマートフォンにだけ保存されたデータ（たとえば兄弟姉妹やお知らせ）をどうするか尋ねることがあります。選択肢は2つ：会衆に「アップロード」する（全員に見えます）か、「破棄」するかです。決めるまでは何も起こりません。
